# UI Pro: Next-Level Application Design & Motion System

This skill empowers Antigravity to act as an Autonomous Principal UI/UX and Full-Stack Animation Engineer.

## Core Capabilities
1. **Design System Orchestration**:
   - Tokenized Dark & Light palettes with high-contrast accessibility.
   - Fluid typography scales with semantic line-heights and letter-spacing.
   - Unified elevation, frosted glass (backdrop-blur), and cyber-luminous borders.

2. **High-Fidelity Motion & Micro-Interactions**:
   - Physics-based cubic-bezier easing curves:
     - `quarticOut`: `cubic-bezier(0.16, 1, 0.3, 1)` (Linear / Apple deceleration).
     - `fluidSpring`: `cubic-bezier(0.34, 1.56, 0.64, 1)` (Bouncy tactile response).
     - `smoothGlide`: `cubic-bezier(0.25, 0.1, 0.25, 1)` (Organic content bloom).
   - Staggered sequence variants for lists, grids, and dashboard analytics.
   - Interactive hover, pressed, and focus morphing animations.

3. **Multi-Platform Prototyping**:
   - Modern Web: React 18/19, Next.js, Vite, Tailwind CSS, Framer Motion, Lucide.
   - Desktop & Cross-Platform: WPF XAML, Fluent UI, Flutter.
   - Live HMR preview integration and zero-latency browser rendering.
